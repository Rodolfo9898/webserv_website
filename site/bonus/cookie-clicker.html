Bonus · sessions

Your score lives on the server.

The browser only holds a session id in a cookie. The score itself is kept by the server in that session, so it survives reloads, and a CGI script reads and updates it on every click.

What the browser holds

A session id, not the score. A cookie marked HttpOnly would not even show up here.

Last request to the session script

POST /cgi-bin/bonus/clicker.py with click=1 or reset=1; GET reads the score.
