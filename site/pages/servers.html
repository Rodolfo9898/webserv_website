Multi-port

Several servers, one process.

A config file can declare many Server blocks, each listening on its own interface and port with its own routes, error pages and limits. The cards below are the servers of the configs in the repository; green means that port answers right now.

Servers

Two servers, side by side

Ports 4444 and 4445 come from multiServerConfig.conf: one config, one process, two different home pages and two different body-size limits.

Start them yourself

One server, the full site

./webserv config/defaultConfig.conf

The bonus build takes the files in config/bonus/ instead.

Two servers in one process

./webserv config/multiServerConfig.conf

Each Server block opens its own listening socket, all watched by the same poll().
