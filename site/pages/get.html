Ask for anything, see everything.

GET reads a resource without changing it. Send one to any address of this server and the inspector shows the status, the timing, every header and the body.

GET

Anatomy of a read

Request line

GET /uploads HTTP/1.1: the method, the path the router matches against the route list, and the protocol version.

Headers

Metadata both ways: Host and Accept from the browser, Content-Type and Content-Length from the server.

Safe and idempotent

A GET must not change anything on the server, so it can be repeated, retried or prefetched without harm.
