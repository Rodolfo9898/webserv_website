CGI

Run programs, not just files.

When a route says a file extension is a CGI, the server stops reading the file and runs it instead. The script's output becomes the response. Watch the journey, then run the two Python scripts yourself.

The journey of one CGI request

Run a script

Both live behind /cgi-bin. Submit normally to open the script's own page, or tick the box to read the raw answer here.

GET get.py

Your text travels in the query string, so the script reads it from QUERY_STRING.

POST post.py

The image is the request body: the server pipes it to the script's standard input.

What a script can rely on

The CGI convention: request data arrives as environment variables, the body arrives on standard input, and anything printed to standard output is the answer.

Environment

Route that enables it

Route /cgi-bin ;
method [GET,POST] ;
entry ./cgi ;
defPage /get.py ;
cgi-bin allowed .py ;
ENDRoute ;

The extension after allowed is what turns a file into a program.
