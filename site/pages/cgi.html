CGI

Run programs, not just files.

When a route says a file extension is a CGI, the server stops reading the file and runs it instead. The script's output becomes the response. Pick an interpreter below, or watch how it works first.

What a script can rely on

The CGI convention: request data arrives as environment variables, the body arrives on standard input, and anything printed to standard output is the answer.

Environment

Route that enables it

Route /cgi-bin ;
method [GET,POST] ;
entry ./cgi ;
defPage /get.py ;
cgi-bin allowed .py ;
ENDRoute ;

The extension after allowed is what turns a file into a program.
