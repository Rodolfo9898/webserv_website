Two scripts live behind /cgi-bin. One answers a GET with what you typed; the other receives an uploaded image through a POST body.

GET get.py

Your text travels in the query string, so the script reads it from QUERY_STRING.

POST post.py

The image is the request body: the server pipes it to the script's standard input.
