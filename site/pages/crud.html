REST · CRUD

One resource, four verbs.

The uploads folder is a REST resource: /uploads is the collection and every file is an item. Create, read, replace and delete files with plain HTTP, and watch each request appear below.

CCreate
POST /succesPost

multipart/form-data. The route's upload path decides where the file lands.

RRead
GET /uploads/<name>

The listing at /uploads is the collection, a link in it is the item.

UUpdate
DELETE + POST

The routes only allow GET, POST and DELETE, so a replace is composed from them, with a rollback.

DDelete
DELETE /uploads/<name>

Idempotent: asking twice leaves the same end state.
